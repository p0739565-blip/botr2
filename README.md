# Makwin VPN — Telegram-бот продажи подписок + админ-панель

Бот на aiogram 3 для продажи доступа к VPN через Telegram, с оплатой
картой/СБП/криптовалютой (через Platega) и Telegram Stars, реферальной
программой, промокодами и полноценной веб-админкой. Работает поверх
уже существующих VPN-серверов (xray/vless) — бот не устанавливает и
не настраивает сами VPN-сервера, только выдаёт клиентам ссылки-подписки
на уже готовые конфиги.

## ⚠️ Прежде чем публиковать/форкать этот репозиторий

В `app/data/` лежат **реальные секреты и данные** — это НЕ шаблонные
файлы, они не должны попадать в git вообще:

- `admin_session.key` — секрет, которым подписываются сессионные cookie
  админки. Если он виден публично — любой человек может подделать
  cookie и получить полный супер-админский доступ к панели без пароля.
- `database.db` (и любые `database.db.backup-*`) — вся боевая база:
  пользователи, платежи, балансы, хеши паролей админов.
- `support_media/*` — реальные скриншоты, присланные пользователями в
  поддержку.

**Если эти файлы уже когда-то коммитились в публичный репозиторий —
их удаление новым коммитом НЕ убирает их из истории.** Их нужно
считать скомпрометированными: как минимум перегенерировать
`ADMIN_SESSION_SECRET`/`admin_session.key` (это разлогинит всех
админов, они зайдут заново по паролю — это нормально) и сменить пароли
админов, а сам репозиторий — либо сделать приватным, либо полностью
переписать историю (`git filter-repo` / BFG Repo-Cleaner), либо начать
новый репозиторий без этой истории. В `.gitignore` внизу эти пути уже
добавлены, чтобы это не повторилось.

## Стек и архитектура

- **aiogram 3** — бот (long polling, без вебхука Telegram)
- **FastAPI + uvicorn** — отдаёт подписки (`/sub/<token>`), принимает
  вебхук Platega, отдаёт админ-панель (Jinja2-шаблоны)
- **SQLite** (`aiosqlite`) — вся база, файл `app/data/database.db`.
  Postgres/Docker **не используются**, несмотря на то что могло быть
  написано в старых версиях этого README/старом `docker-compose.yml` —
  тот файл ничем реальным не пользовался и удалён, как и `Dockerfile`.
- Деплой — обычная VM (без контейнеров), два systemd-сервиса:
  - `vpnbot.service` — процесс бота (`python -m app.bot`)
  - `vpnapi.service` — процесс FastAPI (`uvicorn app.api:app`), сюда
    же встроена вся админка
  - Наружу оба торчат через Cloudflare Tunnel

## Возможности

### Бот
- Пробный период, покупка подписки на 1/3/6/12 месяцев
- Способы оплаты: Telegram Stars, банковская карта, СБП (QR),
  криптовалюта (все три — через Platega), бонусный баланс
- **Пополнение баланса на сумму по выбору пользователя** — отдельно от
  покупки конкретного тарифа: пользователь сам вводит сумму, платит
  любым из тех же способов, деньги зачисляются на баланс
- Реферальная программа — свой режим награды на каждого пользователя
  (дни к подписке ИЛИ % от оплаты на баланс), награда на каждую оплату
  приглашённого реальными деньгами
- Промокоды — скидка на следующую покупку и/или бонус на баланс,
  лимит активаций, срок действия
- Тикеты поддержки — с фото/видео вложениями в обе стороны
  (пользователь → админ и админ → пользователь)

### Админ-панель (`/admin`)
- Дашборд с фильтром периода (сегодня/вчера/7 дней/30 дней/
  произвольный диапазон), графиком оборота, разбивкой по способу
  оплаты, сводкой по рефералам и популярности тарифов
- Пользователи — поиск, фильтр по статусу подписки, пагинация
- Платежи, Тарифы (переопределение цен), Рефералы (настройка бонусов),
  Промокоды (создание/статистика), VPN-ссылки (в т.ч. импорт из
  JSON-конфига Xray/v2rayNG/NekoBox), Рассылки, Админы (роли и права),
  Журнал действий (аудит-лог)
- Ролевая модель прав доступа (`Permission`) — обычному админу можно
  выдать только нужный набор разделов

### Надёжность
- Фоновая сверка платежей Platega (`platega_reconciliation.py`) —
  если колбэк от Platega не дошёл (например, поменялся адрес
  Cloudflare-туннеля), платёж не зависает в "Ожидание" навсегда: раз в
  5 минут статус переспрашивается напрямую через API

## Установка и запуск

1. Скопировать `app/config.py`-переменные в `.env` в корне проекта
   (файл читается через `python-dotenv`):

   ```env
   # Telegram
   BOT_TOKEN=...
   CHANNEL_ID=...
   CHANNEL_USERNAME=...

   # Подписка
   SUB_DOMAIN=https://ваш-домен

   # Platega (оплата картой/СБП/криптой) — docs.platega.io
   PLATEGA_MERCHANT_ID=...
   PLATEGA_SECRET=...
   # PLATEGA_CARD_METHOD / PLATEGA_SBP_METHOD / PLATEGA_CRYPTO_METHOD —
   # необязательны, дефолты 11/2/13 (см. app/config.py)

   # Необязательно, но желательно на проде — иначе сессии админки
   # инвалидируются при переносе на новый сервер:
   ADMIN_SESSION_SECRET=...
   ```

   В личном кабинете Platega (Настройки → Callback URLs) должен быть
   указан `{SUB_DOMAIN}/webhooks/platega` — и он должен быть **актуальным**:
   если он проксируется через Cloudflare Quick Tunnel
   (`*.trycloudflare.com`), такой адрес меняется при каждом
   перезапуске туннеля, и колбэки перестают доходить, пока URL не
   обновить руками в кабинете Platega.

2. Внести реальные VPN-ссылки — либо через код (`app/vless_links_seed.py`
   как сид на старте), либо сразу через админку (`/admin/vless-links`
   → «Добавить», можно вставить готовую `vless://…`-ссылку или сразу
   весь JSON-конфиг целиком).

3. Установить зависимости и поднять оба процесса как systemd-сервисы
   (`vpnbot.service` → `python -m app.bot`, `vpnapi.service` →
   `uvicorn app.api:app`) — см. существующие unit-файлы на сервере как
   образец, если разворачиваете с нуля.

Миграций через Alembic нет — таблицы создаются через `create_all` при
старте `vpnapi.service` (см. `init_models()` в `app/db.py`).
